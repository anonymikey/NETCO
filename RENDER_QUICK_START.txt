================================================================================
                        10-MINUTE DEPLOYMENT STEPS
================================================================================

1. CREATE RENDER SERVICE (2 min)
   - Go to https://render.com/dashboard
   - New Web Service → Select GitHub repo: "netco"
   - Name: netco-api
   - Root Directory: artifacts/api-server
   - Build Cmd: pnpm install && pnpm run build
   - Start Cmd: node --enable-source-maps ./dist/index.mjs
   - Plan: Starter ($7/month)

2. ADD ENVIRONMENT VARIABLES (2 min)
   Copy these into Render Environment section:
   
   PORT=5000
   NODE_ENV=production
   LOG_LEVEL=info
   POSTGRES_URL=<your-database-url>
   SUPABASE_URL=<your-supabase-url>
   SUPABASE_SERVICE_ROLE_KEY=<your-service-key>
   RESEND_API_KEY=<your-resend-key>
   PAYFLOW_API_KEY=<your-payflow-key>
   PAYFLOW_API_SECRET=<your-payflow-secret>
   PAYFLOW_ACCOUNT_ID=<your-account-id>
   VITE_PUBLIC_URL=https://netcom.anonymiketech.online
   VITE_SUPABASE_URL=<your-supabase-url>

3. DEPLOY (3-5 min)
   - Click "Create Web Service"
   - Wait for build to complete
   - Service shows "Live" when ready

4. GET API URL (1 min)
   - Render dashboard shows: https://netco-api.onrender.com
   - Copy this URL

5. UPDATE VERCEL FRONTEND (1 min)
   - Vercel dashboard → netco-platform → Settings → Environment Variables
   - Add: VITE_API_BACKEND_URL = https://netco-api.onrender.com
   - Redeploy frontend

6. TEST (1 min)
   curl https://netco-api.onrender.com/api/stats
   Should return JSON response

TOTAL TIME: ~10-15 minutes

================================================================================
                         TROUBLESHOOTING QUICK GUIDE
================================================================================

"pnpm not found" error:
  → Add "packageManager": "pnpm@9.0.0" to root package.json

"PORT not set" error:
  → Make sure PORT=5000 is in Render environment variables

Database connection fails:
  → Check POSTGRES_URL format and database allows external connections

API doesn't respond:
  → Check service is "Live" → Check environment variables → Check logs

Frontend can't reach API:
  → Verify VITE_API_BACKEND_URL is set in Vercel
  → Make sure it matches Render URL exactly
  → Test with: curl https://netco-api.onrender.com/api/stats

See RENDER_DEPLOYMENT_GUIDE.md for detailed troubleshooting.
