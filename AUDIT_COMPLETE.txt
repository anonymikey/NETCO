EXECUTIVE SUMMARY
================================================================================

ISSUE FOUND: Critical - Config downloads fail in production
IMPACT: Users cannot download config files (404 errors)
CAUSE: Relative URLs stored in database don't work across different domains
SOLUTION: Use absolute URLs with API domain
EFFORT: ~45 minutes to fix
RISK: Low (fully backward compatible)

================================================================================
WHAT'S BROKEN (3 Places)
================================================================================

1. artifacts/api-server/src/routes/orders.ts (line 120)
   - Stores: const configUrl = `/api/orders/${orderId}/download`;
   - Should be: const configUrl = `${API_BASE_URL}/api/orders/${orderId}/download`;

2. artifacts/api-server/src/routes/payment.ts (line 78)
   - Stores: const configUrl = `/api/orders/${orderId}/download`;
   - Should be: const configUrl = `${API_BASE_URL}/api/orders/${orderId}/download`;

3. artifacts/api-server/src/routes/admin-orders.ts (line 100)
   - Stores: const configUrl = `/api/orders/${order.id}/download`;
   - Should be: const configUrl = `${API_BASE_URL}/api/orders/${order.id}/download`;

================================================================================
THE FIX (In 3 Steps)
================================================================================

STEP 1: Set Environment Variables
  - Render: API_BASE_URL = https://netco.onrender.com
  - Vercel: VITE_API_BASE_URL = https://netco.onrender.com

STEP 2: Update 3 Files
  - Add constant: const API_BASE_URL = process.env.API_BASE_URL?.replace(/\/+$/, "") || "http://localhost:3001";
  - Use in URLs: configUrl = `${API_BASE_URL}/api/orders/${orderId}/download`;

STEP 3: Deploy
  - Commit changes to main
  - Render auto-deploys
  - Vercel auto-deploys
  - Test downloads work
